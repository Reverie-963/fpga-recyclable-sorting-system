## 计算与接入

`src/contour_grasp.py` 提取完整实例掩码的前景像素单元边界（中心±0.5），包含内孔。经已有镜头/位姿/物高投影到毫米平面，沿闭合方向求交，仅取包含抓点的实心区间。斜放物体不使用图像水平框宽；孔洞不被凸包填平，单像素测宽不变成0毫米。

统一规划在原内距选点后计算局部 `grasp_width_mm`，与整体 `width_mm` 分开保存。live-object或配置间距表的入口将毫米抓点移到两侧边界中点；画面点取其最近前景像素，仍检查原最小内距。旧已标定样件无间距表时保留原抓点。近圆形采用零度腕角时，邻物张爪包络也同步采用零度坐标轴。

`compile_route(..., grasp_width_mm=...)` 在有有效间距表时，对 `局部宽度-compression_mm` 做分段线性插值，得到闭合PWM。张爪、释放、回中位、速度、等待和原保守张爪避障包络保持；新闭合指令参加完整路线审计。

无表时返回 `jaw_closure.mode=legacy_fixed_pwm`、`width_controls_closure=false`、`limitation=measured_jaw_gap_calibration_missing`，保持原闭合量。**只接入测宽、没有实测表，不会使现场吸管自动夹紧。** 有表但错误、宽度缺失、目标间距超出实测范围或张爪余量不足时拒绝，不回退、不外推、不钳制极限。

## 可选配置与输出

支持 `profiles.<material>.jaw_calibration`（随配方参与原资格指纹），或独立的 `unified_policy.jaw_calibration`（全材质共用）。共用策略必须有非空 `jaw_calibration_operator_statement`，若配方也有表则两者必须完全相同，否则拒绝。

本次启用采用共用策略，原配方、位置/路线资格记录原样保留，不刷新历史资格哈希。`binding.files.jaw_measurements` 绑定启用记录，其内部逐项绑定人工测量文件及原动作报告SHA-256；`src/jaw_measurements.py` 核对来源任务、回执/等待、实际发送的夹爪PWM与整张表，并随实现源码封存。人工读数不等于位置传感反馈，启用记录明确 `physical_grip_verified=false`、`unattended_accepted=false`；新闭合量不能继承历史样件的夹持成功结论。

| 字段 | 契约 |
| --- | --- |
| `kind` | `measured-jaw-gap-v1` |
| `measurement_id` | 非空实测记录标识，不得以模拟值冒充实测 |
| `samples` | 2–32个 `{gap_mm, pwm}`；gap为非负有限毫米数且严格递增；PWM为500–2500整数且严格单调，支持两种方向 |
| 最后一条样本 | 最大实测开口，PWM必须等于原 `open_pwm`；间距不得大于策略 `jaw_open_span_mm` |
| `compression_mm` | 期望收紧量，有限且≥0、小于最大开口；按软垫/样件实测决定，不代表力控 |
| `compression_ratio` | 可选相对收紧比例，默认0，有限且0≤值<1；目标间距=`宽度×(1-比例)-compression_mm`。比例非0时`compression_mm`须为0，避免叠加。用户本轮指定0.2试验，夹持效果仍待实测 |
| `opening_margin_mm` | 每侧开口余量，有限且≥0、小于最大开口；宽度+两侧余量不得超过最大开口 |

`grasp_cross_section` 保存局部宽度、两侧毫米接触边界、中点、轴角、截面实心段数和中心平移量。`jaw_closure` 保存观测宽度、目标间距、最终PWM、模式、实测记录ID及标定SHA256。`physical_contact_verified=false` 明确没有接触反馈。原完整掩码与核验证据保留。

## 后续实物验收

1. 小于9 mm的薄件仍超出现有表范围。用户已暂停扩展，不自动继续收拢；需要时另行明确授权并受监督测量。夹物时串口回显不能代替间距测量。
2. 本次已建立新策略/绑定并完成CPU/PL路线等价检查和部署封存，保留原config及资格哈希。`motion_path_runtime.py` 的路线编译器源码哈希与本次启用前相同；间距换算模块及记录验证器另随实现身份和静态清单封存。以后变更表或编译逻辑须重新验证，不刷新历史资格冒充新抓取验收。
3. 新鲜场景预演、受监督单件接触/抬升/放置核验。投影高度不等于机械下降深度；本轮不改 `grasp_z_mm`，保留低物体保护、图像最小内距和运动限位。

这是指定高度平面的二维轮廓截面启发式，不提供厚度、夹持力、夹指深度范围完整接触模型或三维扫掠体积。透明、反光、遮挡和过窄分割仍可能导致测宽偏差或拒绝；单像素测量测试通过不代表允许抓单像素物体。
