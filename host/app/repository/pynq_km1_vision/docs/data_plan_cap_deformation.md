# 数据补充建议：cap_deformation 数据集扩容（讨论稿）

> 作者：队员 A（识别侧）
> 日期：2026-10-12（2026-10-18 改为建议稿）
> 状态：**建议稿，待队长与队内讨论后对齐**
> 目标：把当前仅用于练流程的 19 张数据集，扩充为可支撑真实训练与评估的独立样本集
> 说明：以下数量、划分和流程均为识别侧的初步建议，具体标本数、采集量和时间安排请队长根据实际情况对齐调整。

---

## 1. 现状问题（为什么需要补数据）

| 现状 | 问题 |
|---|---|
| 每类仅 **1 个标本** | 模型只会认这一个瓶盖，换一个标本可能失效 |
| 同一标本被分进 **train/val/test** | 存在数据泄漏，指标会虚高；`DATASET_NOTE.txt` 已注明"不能当独立精度成绩" |
| 仅 **19 张**图（train 11 / val 4 / test 4） | 数量偏少，YOLO 正式训练参考不足 |

**初步判断**：现有数据目前只能练通流程，暂不适合作为比赛成绩依据。建议在条件允许时补充**多标本、按标本防泄漏划分**的独立数据集。

## 2. 建议目标数量（参考值，待队内对齐）

- **正常瓶盖 `cap_ok`**：建议每类 **60 张左右**独立样本（如时间紧张，底线 30 张也可先跑通）
- **变形瓶盖 `cap_deformed`**：建议每类 **60 张左右**独立样本（同上）
- 关键建议：**多个独立标本**，而不是同一个瓶盖拍几十次

## 3. 建议标本准备（待队内对齐）

- **正常**：建议准备 **5~8 个**不同瓶盖标本（具体数量视手头样件而定）
- **变形**：建议准备 **5~8 个**不同变形瓶盖标本，尽量**覆盖不同变形程度**（轻微翘边 → 明显凹陷/挤压）
  - 初步判断：变形程度的覆盖面对缺陷类模型比较关键，建议尽量拍到边界情况

## 4. 建议采集维度（供参考）

| 维度 | 建议 |
|---|---|
| 光照 | 可覆盖 2~3 种（正常室内 / 偏暗 / 侧光），以实际工位光照为主 |
| 位置 | 瓶盖在画面不同位置、不同朝向 |
| 变形程度 | 从轻微到明显都尽量覆盖，重点拍边界情况 |
| 方式 | 用实际相机（C270 同视角）拍摄，或产线视频抽帧；保证清晰不糊 |

> 💡 建议背景尽量与实际工位一致，避免模型学"背景"而非"瓶盖"。每张之间让瓶盖真实改变位置/角度。

## 5. 标注规范（识别侧建议）

- 工具：**labelImg**（导出 YOLO 格式）
- 每行格式：`class x_center y_center w h`（归一化 0~1）
- class 映射：`0 = cap_ok`，`1 = cap_deformed`（与 `cap_deformation.yaml` 一致）
- 框建议贴紧瓶盖外轮廓，不包含背景；只标画面内完整/可见的瓶盖

## 6. 划分建议（防泄漏）

- **按标本划分**（识别侧建议）：同一标本的所有照片建议全部落在同一个 split，避免同时进 train 和 test
- 参考比例：train ~70% / val ~15% / test ~15%（可根据实际标本数调整）
- 建议刻意保留部分标本"完全没进过训练"，用于测试泛化能力

## 7. 文件命名建议

现有文件名是时间戳（如 `1746293xxx.jpg`），无法区分样件。建议补数据时采用新命名：

```
<类别>_S<标本号>_<光照>_<序号>.jpg
示例：cap_deformed_S03_L2_005.jpg
```

命名携带标本号后，后续可写脚本自动检查"同一标本是否跨 split"。具体命名规范可由队长定。

## 8. 补完后自查清单（供参考）

- [ ] 每类独立样本数量达到队内约定的目标
- [ ] 标注框正确、无空标签、无错类
- [ ] 同标本不跨 split
- [ ] 抽查标注质量（框是否贴紧外轮廓）

## 9. 后续更新

- 补完后建议更新 `DATASET_NOTE.txt`（标本数、划分、数据来源）
- 建议维护数据清单（标本 ID、采集场次、拍摄条件），供报告"模型与数据说明"一节使用

## 10. 参考执行流程（非强制）

1. 备标本（正常 + 变形各若干）
2. 用实际相机/视频抽帧采集，覆盖光照/位置/变形程度
3. 按约定命名规范整理
4. labelImg 标注
5. 按标本划分 train/val/test
6. 自查清单
7. 更新 DATASET_NOTE + 数据清单
8. 交给 train_yolo.py 训练
