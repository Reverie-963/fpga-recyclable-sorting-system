监控页面新增“加速实测”区域，分别展示典型单帧中位速度比、包含卡顿的整批速度比、CPU/GPU原始耗时；折叠详情保留测量日期、CPU线程、batch、测量次数和相同FP32速度比。区域明确标记“离线基准 · 非实时倍数”，上方实时帧率和耗时保持独立，避免把历史CPU耗时除以当前GPU耗时冒充实时加速。

只读`GET /benchmark`根据当前健康信息返回相应摘要：须匹配模型SHA-256、模型族、精度、推理策略、GPU名称、PyTorch/HIP和MIOpen设置。父模型换成续训权重后不会套用旧成绩；报告缺失、配置不符或数据异常时返回`available=false`，界面隐藏该区域，不阻塞识别。11s同样自动匹配自己的记录，FP32启动时改用FP32数据；整批慢于CPU时保留小于1的真实比值。
