一次开始，停稳自动拍

  1. 相机固定，保持当前分辨率和焦距/对焦设置。
  2. 拿棋盘缓慢经过画面左、右、上、下，前后左右倾斜约15～30度，适当改变远近。
  3. 完整露出20个内部交点，停稳约一秒；助手检查清晰度与重复姿态后自动保存。
  4. 进入保留检查阶段后，再换三个不同位置。照片够用后自动计算。

无需逐张按快门、起文件名、量棋盘高度或手动录入角点。质量未通过时先停止并检查原因，不反复按张数追加照片。

把坐标登记也放进同一次操作

  1. 固定标记板平整贴在工作面，不垫高，不改变四枚标记的相对位置；至少三枚能被相机完整看见。
  2. 把旧棋盘恢复到此前标定的位置与朝向，与标记板保持同一平面。原位置不确定时先暂停，不能随意放置后确认。
  3. 看画面标注：C2是原点，D2在原卡右侧，C1在原卡上方；若反了，切换180度方向。
  4. 确认后点击登记，助手同时识别两块图案并自动提取20组坐标，保留其中8组检查。无需手量五组位置。

首次登记仍需要原定位依据。自动读点不能找回一张被随意移动过的旧卡原点。
