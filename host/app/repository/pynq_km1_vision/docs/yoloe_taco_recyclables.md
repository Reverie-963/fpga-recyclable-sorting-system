## 启动与入口

当前用户指定入口为最近的抓放中控台 <http://127.0.0.1:8810/>。仓库根目录先运行 `./tools/start_yoloe_recyclables.ps1`（8811 识别服务），再运行 `./tools/start_prompted_console.ps1`（8810 中控台）。同端口旧进程须先停止。服务启动和重启均暂停实时识别。

8810 复用原 `dashboard.html`、任务记录、性能和图片识别界面；原实时/图片接口已经适配新模型，显示原始标签及材质。默认打开“YOLOE · 24 类与空背景”页，可拍一帧、上传图片、实时识别、修改提示词/阈值/高度、记录空背景及预览路线。浏览器通过 8810 同源代理连接 8811，背景照片链接也经中控台查看。原历史运动监视保留；此入口的旧模型动作调用被明确拒绝，避免沿用旧视觉资格执行新类别。

默认模型是官方 `yoloe-11m-seg.pt`，保留官方权重，不是经过 TACO 训练或微调的新模型。文字编码复用独立 CPU 环境，检测复用已部署 ROCm 环境。资产及依赖见 [官方模型试用说明](yoloe_official_monitor.md)。模型、环境、图片与运行日志仅本机存在，不随 Git 同步。

### 空背景记录（2026-10-30）

按队长决定暂不训练模型。页面复用原监视器样式与三栏布局，保留原始画面、识别画面和双画面对照，在左侧加入空背景记录。

使用方法：先查看原始画面，清空源区和三个分类箱，保留固定箱体、机械臂、定位标记，手退出画面；勾选空场确认，再点“记录当前空背景”。记录后可从列表查看和下载原图，重启服务后仍保留。服务拒绝缺少明确空场确认、缺少相机帧或超过两秒的画面。

原始相机 JPEG 和记录元数据保存在 `local-only/yoloe-recyclables/empty-backgrounds/`，每条单独编号、追加保存，包含时间、相机流/帧编号、图片哈希及设置身份。元数据最后写入，未完成写入的照片不列为有效记录；读取图片校验哈希。操作者确认不等于机器自动验证空场，记录不会自动成为训练负样本或物理验收证据。

当前只保存、查看空场对照图，**尚未用于自动背景扣除或过滤识别结果**，也不修改板端诊断基线、运动绑定或模型权重。不能将有物体的现场画面替用户登记为空背景；本轮只用模拟画面测试记录成功链路，实际空场留待操作者清空后记录。

新增 `GET /backgrounds`（最近 30 条记录及当前相机流）、`POST /backgrounds`（`confirmed_empty: true`）和 `GET /background/<id>.jpg`。专项检查覆盖确认/帧龄拒绝、照片与帧身份、跨重启保存、篡改/路径拒绝、未完成记录及完整 HTTP 保存查看流程；与已有识别专项共 30 项。浏览器布局仍需用户实际查看，不宣称完成浏览器视觉验收。

## 类别和分区

[配置](../config/yoloe_taco_recyclables.json) 固定引用 TACO 作者仓库提交 `70479ad9adc3da971a8ae75ac97eb1026910eec7` 的 [map_10.csv](https://github.com/pedropro/TACO/blob/70479ad9adc3da971a8ae75ac97eb1026910eec7/detector/taco_config/map_10.csv)。该映射表有 64 条原始名称，保留大小写和原始拼写；不是宣称标准 TACO 数据集共有 64 类，也不把行号当作官方类别 ID。

当前仅保留 24 个原始标签：纸 8、塑料 9、金属 7。按队长后续明确要求，其他 40 个已从模型输入提示词、页面候选类别和保存配置中移除，选择类别时也不会自动补回。64 个名称仅为来源映射表的规模。旧的 64 类设置已在本机另存备份，原有三类高度/阈值保留。移除标签不保证模型会忽略对应物体，仍可能漏检或将其误归为这 24 类；类别名不证明物体清洁度、实际材质或回收资格。

每个识别实例保留 `label` / `official_label`、提示词序号 `class_id`、分数、原图掩膜；另加 `material`、`sorting_bin`、`semantic_gate_passed` 与原因。运动适配器只在内部把 `label` 投影到原有三类接口，仍保留 `official_label`。同材质但不同原始类别不能通过三帧类别稳定性检查。

投放区使用当前冻结机械配置中的 `bin_paper`、`bin_plastic`、`bin_metal`；加载时核对映射。不会改写现役板端区域、基线、机械参数、活动绑定或语音入口。

## 阈值与高度

- 检测底线 0.10：低分物体也保留掩膜参与障碍检查。
- 显示门槛默认 0.25，只控制图和表的显示。
- 各材质候选门槛默认 0.65，落料验证门槛默认 0.70；各原始类别抓取门槛默认 0.75。
- 实际语义门槛取对应类别门槛与所在区域门槛的较高值。落入其他材质投放区的实例不能通过。
- 这些数值均为待验证初值，不是准确率结论；不继承现役旧模型被放宽的全局置信度。
- 高度单位 mm，允许 1–120，表示物体顶部相对桌面的高度。默认纸 65、塑料 53、金属 56 来自历史样品，仅作输入初值；不代表同材质所有物品都等高。当前每种材质一个高度，同材质不同高度应分开逐件预览。
- 高度用于带畸变修正的相机射线与高度平面求交，不直接更改抓取 Z、夹爪参数或已记录落料路径。

应用后设置原子保存至 `local-only/yoloe-recyclables/settings.json`，与类别策略、提示词、阈值、高度一起计算身份哈希。策略改变时拒绝静默套用旧设置。重启仍暂停实时识别。

## 运动接入边界

`src/sorting_prompted_preview.py` 读取并校验现役不可变绑定，重新采集三个带身份的相机帧、定位固定标记，再使用同一个新模型识别三帧。检查图片/掩膜/设置身份、原始标签稳定性、几何与 RGB 稳定性，然后调用已有 `UnifiedController.candidate` / `compile_route`：保留尺寸范围、夹爪间距、碰撞检查、空投放区、可达范围和整条路线编译。

所有已检测的低分实例保留；遇到排除/未知实例时保守阻止整个路线预览，不借其他类别的高度去映射未知物体。此策略也可能因投放区内的排除类而阻止源区预览，是当前明确限制。

该入口只有预览，没有 `/execute`、串口打开或板端区域写入。使用冻结相机快照生成的路线不能直接执行；历史样品的抓取能力不自动转移到新标签或新高度。落料门槛的通用判定和投放区判断已接入，真正动作后的新模型闭环复核尚未进行。后续实物联调需完成原始标签/高度/尺寸/夹持参数核验，再建立新的运动绑定，不能修改旧记录来绕过检查。

HTTP 接口（仅本机同源）：

| 接口 | 作用 |
|---|---|
| `GET /policy` | 类别来源、原始标签与材质映射 |
| `GET /health` | 已应用设置、暂停状态、相机与运行环境 |
| `POST /configure` | 提示词、分区/类别阈值、高度、实时开关 |
| `POST /detect` | 上传图像或相机单帧；返回原始标签、掩膜和分组 |
| `GET /live-result` | 新鲜实时结果，暂停时不返回旧结果 |
| `POST /plan` | 使用当前设置和三帧实时图像生成只读路线预览 |

8810 上述新接口统一位于 `/prompted/` 前缀；另有适配原页面的 `/health`、`/live-result`、`/live`、`/detect`。原始标签保留于 `official_label`，仅在原界面兼容接口内将 `label` 投影为材质。`POST /operation*` 拒绝旧模型机械命令。

24 类中控台部署补验：33 项相关检查通过，包括同源页面/图片链接代理、原接口标签投影、健康身份及原动作入口拒绝；真实相机经 8810 返回 `Other plastic bottle` 约 0.82、`Drink can` 约 0.41，未评定类别准确率。实际空背景入口可读，识别仍暂停，无模型训练或机械动作。页面脚本语法及仓库检查通过，未做浏览器视觉验收。本机证据为 `local-only/yoloe-recyclables/console-24-verification.json` 及 `console-24-check.json/jpg`。

## 本轮验证与实际结果

- 专项 25 项（新适配 15、原监视器 10）通过；现有运动/相机相关 112 项通过，共 137 项。三类模拟实例均可编译原运动路径，未打开串口；非法高度、原始标签跳变、掩膜绑定变化、低分/未知障碍、阈值优先级与参数保存均有检查。
- 页面脚本语法、仓库轻量检查、真实 HTTP 页面/参数入口、无效高度拒绝、参数恢复、同图修改阈值和只读三帧预览通过。浏览器点击与布局未做自动验收，不宣称已完成浏览器视觉验收。
- 官方模型 64 个提示词在 GPU 上实际运行。现场画面中的瓶状物被标为 `Disposable plastic cup`，约 0.82；另有 `Aerosol`、`Cereal bag`、`Drink carton` 等输出。因此不能宣称细分类别准确，也不能仅靠提高阈值保证正确。相同原图把该类别门槛从 0.75 调到 0.90，实际验证了语义门槛由通过转为拒绝，原标签和材质映射保留。
- 真实三帧预览返回 `excluded_or_unknown_object_in_scene`，未生成可执行动作、未移动机械臂。结果位于 `local-only/yoloe-recyclables/verification.json`，相同图阈值对照为 `threshold-before.json` / `threshold-after.json`，相机原图、推理和预览报告保存在 `previews/`。这些是本机证据，没有共享下载地址。
- 未进行新模型物理抓放、板端综合/位流更新、机械精度、吞吐量或三类准确率验收；本轮无 PR。
