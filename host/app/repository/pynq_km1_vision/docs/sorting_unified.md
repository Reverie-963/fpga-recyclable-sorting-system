## 操作

根目录使用同一启动器：

```powershell
./tools/start_sorting_loop.ps1 -Unified -Mode Preflight
./tools/start_sorting_loop.ps1 -Unified -Mode Preview
./tools/start_sorting_loop.ps1 -Unified -Mode Execute -Ready
./tools/start_sorting_loop.ps1 -Mode Stop
```

统一入口同时处理单件与多件。默认一次最多6件、1200秒，达到上限退出；可用 `-MaxTasks`、`-MaxSeconds` 调小。只处理本批开始时同时放好的物品，执行期间不继续放入新物品。必须保持已测样件分开、不接触、固定标记可见，机械臂中位张爪且人员撤手并在场。程序没有新增人体/撤手检测。

新版网页本机服务为 <http://127.0.0.1:8788/>，启动方式 `./tools/start_sorting_monitor.ps1 -Port 8788`。绑定含 `files.unified_policy` 时自动显示“开始本批分拣”，可自动选三类或筛选某一类。类别筛选仍把其他物品保留为障碍和待处理实例。待命先见空区，再等一批稳定目标，最多120秒等待，一批结束或异常即退出。页面失联仍请求停止，不自动开启下一批。统一模式接口版本2，旧页面遇到新版接口应阻断，刷新至新版页面再操作。

预演仅采图、识别、计算和保存预演记录，不打开机械串口、不设置PL区域或基线。执行持有原全局账本锁及设备租约，贯穿整批观察、逐件运动和件间间隔；原单件/语音入口不能在中途抢占。新模式不改变 `-KnownItem` 的原单件兼容行为。旧8779/8786进程未替换；停止本轮8787早期进程被自动审批拒绝、未提供具体原因，故保留它并另在8788启动最终版。旧进程仍冻结旧绑定，不能代替新版。

## 逐件事务

当前绑定 `motion_guard_policy.min_fixed_markers=2`，初始位姿及动作检查最低2枚不同已登记ID；旧绑定缺省仍3。三帧稳定性、覆盖/重投影/歧义/毫米稳定性以及5像素与图块检查不变。两共同标记使用最后已验证位姿，三枚以上保留均值角点位姿；不改变原相机/世界登记与机械资格。公开预检字段min_fixed_markers可核对现役值。

当前空箱外观上限由独立 `empty_bin_max_changed_fraction=0.2` 控制，允许参考画面20%的RGB差异；不影响5%场景限制或语义占用。每次候选的slot_checks记录实际变化/上限/占用，20%不是“允许箱内已有物体”。设备批次租约现在保存JSON的kind/pid/token，仍整串核对所有权；页面重置仅能在任务结束、现场确认且证明owner已退出时归档清理遗留租约，无PID的旧锁不强行删。

1. 新鲜三帧识别当前取物区内的全部实例，用类别与掩码重叠建立唯一匹配身份。检测返回顺序变化不会交换同类物品身份；缺件、合并、明显移动或新增实例均停止。
2. 各候选按所属样件高度将像素射线映射到毫米，检查面积、尺寸、完整轮廓、间距和抓点内部距离。长轴不清楚时拒绝猜测腕角。
3. 由位置与主轴角计算底座和腕角，按平行夹爪180度对称选择腕部解；接受0～360度平面方向输入。先生成整条高位、下降、闭爪、抬升、按类转运、释放、返回中位路线，再检查每个包、逆解及关节插值的名义高度。数学可达并不证明实际无碰撞。
4. 所有其他取物区实例都参与名义张爪包络检查，包括相同类别与被筛选掉的类别。包络没有覆盖完整机械臂连杆或搬运物体的扫掠体积；密集、重叠和遮挡堆叠不属于已验收场景。
5. 每件开始前重拍并绑定准确PL原图基线，每条动作保留固定标记/图块、流身份、时效、停止、串口完整回显及等待检查。低速关节5秒、夹爪2秒，释放额外停稳1秒。
6. 默认兼容策略仍逐件核验。当前授权策略 `batch_verification_mode=end_of_batch` 在完整抓放退回后记录本件视觉结果，视觉失败仍进入下一件新鲜场景检查，最后统一核验；传输/定位/停止异常仍中止。已尝试对象不重复抓，留在源区时继续作为障碍并在最后判失败。整批末三帧检查源移除、其余物品、入箱类别/数量/落点及RGB持续变化；PL末帧身份核对不冒充整批全局PL差分，见[批末策略](../../docs/team/reviews/2026-10-30-end-batch-verification.md)。

动作前/动作中仍2秒帧龄，终态窗口/有效期仍5秒，不重发机械命令。当前显式统一策略候选/终检置信度0.4、匹配IoU0.9、场景/其他箱允许变化5%、主连通域0.95、源消失0.8、持续重叠0.6。旧默认策略与KnownItem资格不改，5像素及其余机械守卫保留，终态检查后恢复原动作时效。新版手动页 <http://127.0.0.1:8796/>。

## 模型、位置与箱容量

带哈希的 `supervised-unified-sorting-v1` 策略记录三类独立高度、原机械映射、候选俯仰路线、底座/腕角标量、取物区毫米多边形、名义夹爪包络和落点。奶盒继续采用已试过的50毫米抓取模型与10毫米径向补偿；金属56毫米、塑料53毫米高度，各自10毫米名义抓取模型，不借用奶盒65毫米物高。金属、塑料扩展位置/角度的标量先验仍需实抓验证。

取物区多边形为旧纸卡系 X −110～90、Y −65～115毫米，由既有世界登记投影回当前画面；中心允许在该多边形内提出候选。完整轮廓、名义半径、逆解、舵机范围、插值与障碍检查仍可能使部分位置不可执行。“接受全角度计算”不是桌面每一点、每一种摆放都能抓取的保证。原已测小点域、三类资格与生产验收标记均保持原样；策略明确 `workspace_physically_qualified=false`、`unattended_accepted=false`。

目前每类仅启用原已测的一处释放路线。任一已有物体或明显RGB变化占用该落点时，不复用、不盲目堆叠。因此三类混合可按空落点逐件执行；同类多件真实连续放入同一箱仍需补齐多个落点实测。代码支持非重叠落点，每个新增实际路线须有独立绑定的 `verified-bin-slot-v1` 记录，包括该类别、落点内容指纹和真实试验/操作者确认。`candidate` 落点只能预演或模拟，不能作为物理执行许可。原落点不能改坐标后仍冒用原资格。
