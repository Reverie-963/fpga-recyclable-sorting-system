## 拍照与暂停

勾选摆放/手退出确认后按空格或“拍这一张”。等待至少1.5秒及请求之后3张不同新帧，从中选区域最清晰的一张，保留三帧的运动/清晰度诊断。进入正式姿态采集后可用连续模式，每项至少8秒，Esc暂停；移动、过期、模糊、完全或近似重复则等待。可暂停后跳过、撤销；参考照不能跳过。撤销原图移到`rejected/`并保留日志，重拍不覆盖旧拒绝图。

稳定检查不是手检测、身份识别、轮廓复核或机械验收；操作人仍需核对实物和手是否退出。全部正式照片初始`annotation_status=pending`，不伪造空标签或轮廓，标注复核后才可参与正式训练。

空景原36/12/12项过多，按现场反馈取消；当前每个实际场次先拍1张全工位纯空景。空景的清晰度、稳定性和去重检查覆盖整帧，箱区真实照明变化不会再因为源区没变而被误拦；同一场次近似重复仍拦截，不同实际场次可保留各自独立拍摄的同一固定空工位外观。纸卡固定不动，不为制造差异移动相机、箱子或机器人，也不要加入U盘、碎纸等材质或目标范围未明确的物品。错箱物仍标真实材质，固定纸箱始终为背景。

## 启动、恢复与后续场次

在仓库根目录，用已有OpenCV/NumPy环境执行。路径均以根目录为基准，所需旧照片与本机清单必须真实存在；不复制凭据、不自动下载资料。

```powershell
.\.venv\Scripts\python.exe tools/collect_recyclables_final.py --output local-only/recyclables-final-16-v1 --registry local-only/recyclables-final-16-v1/prepared_registry.json --previous-manifest local-only/recyclables-240-no-gum-20261028/dataset/split_manifest.json --session fixed16-train-20261028 --workcell fixed16-20261028 --split train --port 8775
```

恢复使用完全相同的output、registry、session、workcell、split，读取原参考照片和进度，不覆盖已拍图片。数据根的独占锁拒绝并行写入。结束当前实际采集场次可点“结束本场次”，后台保存进度并正常退出。验证/测试必须在训练采集真正结束、换成相应实物后的新实际场次进行，再使用`--split val`或`--split test`和对应新session；不能只改session名称伪造独立场次。开始验证/测试之前必须先完成新增实物编号登记。

相机源只提供JPEG与画面年龄，清单明确没有板端曝光时间戳，本机接收序号不能解释成板端时间。过期/断线取消连续采集，恢复后需操作人重新开始当前项。工具不导入机械臂、串口或PL，不做模型推理、GPU训练、烧写或自动运动。
