# 三类模型扩训与高效素材收集

后续用户要求取消小批试训，当前正式入口为[最终训练方案与一键脚本](recyclables_final_training.md)：三类共用YOLO11n-seg，当前16件、最低507张有效分组数据、100轮上限、固定验证/封存测试流程。早期[按失败场景补数据](recyclable_collection_training.md)保留为历史开发记录。

本次针对已经人工确认的 `can / plastic / cardboard` 材质三类模型。塑料吸管可属于 plastic；是否可夹取仍由几何和机械条件决定。旧 `plastic_bottle` 窄类别数据保留，不能仅改名字冒充材质模型。训练入口读取清单中的显式 `class_names`，兼容上述两套固定顺序；无字段时保持旧瓶类语义。

2026-10-28 本轮结果：新增 120 张公开轮廓图片，完成混合训练 20 轮、现场适配 9 轮并比较新旧候选。最高置信目标达标仍以旧模型 8/15 较好，新候选最好为 5/15；因此保留旧模型。工具和素材已可复用，下一轮先补现场独立实物与背景干扰数据，不能据本轮增加了训练量声称识别精度提升。

## 优先使用的网上素材

1. [TACO 作者仓库](https://github.com/pedropro/TACO)：有 COCO 实例轮廓。使用作者的 [1.0 标签标注](https://raw.githubusercontent.com/pedropro/TACO/1.0/data/annotations.json)，避免追随 master 后下载地址变化；记录实际文件 SHA-256。按原始类别名映射，三类各设图片额度，不下载全部无关类别。
2. [TrashNet 作者仓库](https://github.com/garythung/trashnet)：有纸板、塑料、金属分类图片，但原版没有实例轮廓。适合后续补充外观，需再做分割标注；不能直接投入本项目分割训练。
3. 搜索引擎、电商图和来历不清的聚合包只作待审线索。优先选择能追溯来源、标注格式和许可的数据。原 TACO 工具代码的 MIT 不等于每张照片都采用 MIT；清单保留逐图 license，缺失写 null。本轮公开图片仅留本机研究，不上传 Git 或宣称已取得图片再分发许可。

TACO 是户外垃圾场景，和桌面俯视分拣有分布差异；公开数据用于扩大外观覆盖，现场数据用于决定模型是否适合工位。公开数据里的软袋、吸管、瓶盖即使能识别，也不自动进入可抓取对象范围。

## 已实现的收集入口

在工程目录运行，路径按本机实际数据填写，输出使用一个全新的目录：

```powershell
..\.venv-rocm\Scripts\python.exe -m src.prepare_recyclables_public --base ../local-only/recyclables-local-training-20261027/dataset-reviewed-v2-plastic --output ../local-only/recyclables-web-training-20261027/dataset-mixed-v1 --cache ../local-only/recyclables-web-training-20261027/taco-cache --per-class 40 --workers 4
```

行为与限制：

- 保留本地训练图，逐字节复制本地验证/测试图及标签，公开数据全部放训练集；不重新随机拆分现场图片。
- 按类别名映射所有目标实例。遇到未标明垃圾、材质歧义、过小或无效目标、多段轮廓、RLE/crowd 时排除整张图，避免漏标目标被当作背景或一个实物被拆成多个实例。
- 不用矩形框生成分割标签。公开轮廓按原图宽高归一化，图像缩小后保持对应关系；拒绝宽高比明显不一致的下载图。
- 并发下载有上限，支持缓存，逐图记录原地址、来源编号、原始字节和输出图片哈希、原类别映射。失败列入报告，不计为已下载。
- SHA-256 排查完全重复，64 位图像差异哈希排查近似重复；后者不是同物理样件、裁剪或不同视角泄漏的完整检测。网上图片缺乏可靠实物编号，所以一律不用于本队独立测试。
- `--per-class` 是按包含该类的图片分桶额度；一图可能有多类、多实例，实例数不会严格相同。来源不足时报告实际数量，不复制补齐。
- `previews/` 中每类生成至多 12 张轮廓预览，供抽检。几何校验和作者标注不等于本队逐图人工批准，报告保留此区别。
- 缓存和数据放忽略目录，原数据和既有权重均保留；输出已存在就拒绝覆盖。

输出：`split_manifest.json`、YOLO 轮廓标签、`public-data-report.json`、`previews/`。缓存中固定保留标注 JSON 和下载图片，后续扩大额度可复用缓存并指定新输出目录。

## 从已有模型继续训练

```powershell
..\.venv-rocm\Scripts\python.exe -m src.train_segment --dataset ../local-only/recyclables-web-training-20261027/dataset-mixed-v1 --check-only
..\.venv-rocm\Scripts\python.exe -m src.train_segment --dataset ../local-only/recyclables-web-training-20261027/dataset-mixed-v1 --weights ../local-only/recyclables-local-training-20261027/runs/pilot640-20261027-03-plastic/weights/last.pt --project ../local-only/recyclables-web-training-20261027/runs --name webmix-v1 --device 0 --epochs 20 --batch 2 --imgsz 640 --lr0 0.0005 --patience 8 --augmentation conservative --native-backend
```

这里是加载已有权重，在扩大后的数据上重新建立优化器微调；并非恢复原优化器继续同一训练。保守增强关闭 mosaic/mixup/copy-paste，使用较小旋转、平移和缩放，避免强拼接改变抓取场景。固定 ROCm 原生 GPU 路径、FP32、workers=0，沿用现有已跑通的环境。本轮不安装新环境或升级工具链。

先检查实际训练耗时和现场验证结果，再扩大到每类 100～200 张。不能把一批近似图片复制多份或增加 epoch 当作增加数据多样性。若混合数据使现场效果下降，候选单独保留，可用原现场训练集做后续小学习率微调；不要自动替换正在使用的模型。

现场适配阶段只使用原训练图，可以在另一个新运行目录以 `--lr0 0.0001 --warmup-epochs 1 --warmup-bias-lr 0 --epochs 10 --augmentation conservative` 启动。初始混合轮次沿用 warmup=3、bias warmup lr=0.1；后续适配显式降低 bias warmup，防止短训练的预热学习率远高于指定的小学习率。每阶段均记录实际参数，验证图不能混入适配训练。

比较使用同一现场验证集和同一置信阈值，分别记录类别正确、轮廓 IoU、误检和漏检，检查 best/last；训练 mAP 提高不能代替这个比较。该验证集已被用于选模，不是封存测试集。正式验收需要新实物、新场次，单独冻结测试集后只作最终评估。

单目标现场验证可用 `src.evaluate_segment_pilot` 复现固定阈值对比，提供 `--dataset`、本机 `--weights`、全新的 `--output` JSON 路径，以及本机需要的 `--native-backend`。该入口只读取 val，不评估 test；固定 640、confidence=0.25、mask IoU≥0.5。它分别统计最高置信候选达标、有任意正确候选达标、额外检测和空场景误检，防止同一目标的重复轮廓被重复计为成功。验证图超过一个目标时明确拒绝，不能拿该调试指标充当多目标 mAP。输出包含验证图及标签摘要，便于确认比较使用同一数据。

## 现场采集：优先换实物，再换姿态

下一批建议每类累计 10 个不同实物，作为采集目标而非精度承诺。先给实物贴编号并确定所属集合，再拍照，避免拍完随机拆帧。

| 集合 | 每类实物数建议 | 场景与用途 |
| --- | --- | --- |
| train | 6 | 每件 8～12 个有效位置/方向，至少两个专属训练场次；已有训练件可计入 |
| val | 2 | 不同实物，专属验证场次；用于调参和选模 |
| test | 2 | 额外实物和专属测试场次；封存，最终评估前不看结果 |

不同集合不能共用同一实物、同一采集场次或相邻视频片段。一个多物体场景中的所有实物必须属于同一集合。空场景也按场次分组。

优先补当前薄弱情况：银色反光罐、不同品牌/颜色罐、透明空瓶、去标签瓶、不同外形塑料制品、不同纸盒和奶盒；每类都覆盖中心/边缘、长轴方向变化和实际照明。奶盒按本项目既有确认归 cardboard，复合材质定义写入清单。弯折、破损、不可夹取样件单独记录，避免把识别覆盖写成抓取承诺。

最省标注的方式是固定相机录短视频，物品每摆一个姿态停稳再取一张清晰图；不连续抽大量相似帧。先按时间间隔、清晰度和近似哈希筛选，再由现有模型或分割工具辅助轮廓，人工修正透明边缘、反光、阴影和截断。每张可见目标都要标，空台面保留显式空标签。保留原视频和筛选清单在本机，不将视频提交 Git。

原现场验证图里物品占画面较小，固定收纳纸箱和机械臂也可见。下一批先明确最终待分拣区域及相机视角；如采用区域裁剪，采集、标注和后续推理须使用一致的裁剪及坐标还原。不能只在训练时裁剪、上线仍用另一套画面，也不能把固定收纳箱的误识别当作已经解决。

额外采 30～60 张真实空台面/夹爪/纸卡/箱沿干扰图，主要用于减少误检。先核对图里没有目标物品，不能把含奶盒或瓶盖的场景标成空场景。预览错误、低置信和多余轮廓应进入下次优先标注队列，而不是重复拍已经识别稳定的姿态。
