## 2026-10-30 四个统一入口：每次完整抓放以20秒为目标

当前全部分类、纸、金属、塑料四个入口共用版本化策略中的 `motion_timing`。
本机新版页面为 <http://127.0.0.1:8790/>，旧页面冻结旧绑定，不能仅刷新旧页面代替后端更新。
本轮队长最终选择“先只完成加速配置，暂不实抓”；当前只交付配置、程序和预演结果，不声称已经达到实物20秒。

原统一入口普通关节每段5000毫秒、夹爪2000毫秒，普通段另停0.5秒、释放另停1秒。
新策略逐关节按实际脉宽差计时：底座最多700 PWM单位/秒，其余关节900；普通段至少400毫秒、取物区各升降段至少500毫秒、准备至少1000毫秒，夹紧至少750毫秒、释放至少650毫秒。
各段实际时长取上述下限与全部涉及关节的位移/速度预算的最大值，协议T字段与执行等待一致；夹紧另停0.2秒、释放另停0.3秒，其他段不额外停顿。
这些速率是受监督试验参数，不是测得的舵机硬件极限。

所有原关节目标、途经点（包括零位移点）、抓取/放置位置和顺序保留，不删避让点、不合并路径、不让下一条指令覆盖尚未完成的运动。
每条动作仍执行相机/固定标记、帧龄、流身份、停机与回显检查；三帧识别及终态语义/RGB/PL核验保持。
模板见 `config/sorting_motion_20s.example.json`；它仅为时间参数，需要以实际操作者指令记录到工位策略并绑定实现文件。
策略缺少 `motion_timing` 时仍使用原低速行为。CLI原 `-KnownItem -MotionProfile compact` 保持独立，四入口提速走 `-Unified`。

当前实际三类参数在15个位置、每15度一档共1080条名义路线检查通过，纯运动加停稳预算为塑料12.636～13.170秒、金属12.214～12.748秒、纸12.330～12.864秒。

## 入口与回退

```powershell
# 当前配置选中的档位；不连接机械臂
.\tools\start_sorting_loop.ps1 -KnownItem -Mode Preflight

# 明确预览快档，不发送指令
.\tools\start_sorting_loop.ps1 -KnownItem -MotionProfile compact -Mode Preview

# 单件受监督快档试验，沿用原来的现场摆放条件
.\tools\start_sorting_loop.ps1 -KnownItem -MotionProfile compact -Mode Execute -Ready

# 显式使用原来低速档
.\tools\start_sorting_loop.ps1 -KnownItem -MotionProfile qualified -Mode Execute -Ready
```

本机 `known.motion_profile` 可选择 `compact` 或 `qualified`，命令行优先；缺省字段仍使用原低速档。当前本机选择快档，原坐标、夹爪力度、模型、视觉阈值及资格原始文件保持原值。配置副本和实施源码哈希变更单另存本机，旧几何资格仅说明基线路径和样件，快档明确标记为受监督动作试验，不继承新速度或新路径的物理验收。原生产与无人值守门槛继续独立。

每条指令前保留固定标记守卫、停机检查、完整回显和完整运动等待；异常仍锁存且不重发。终态三帧、源区消失、正确箱新增及其他物体稳定性检查保持原值。

另一个会话按队长要求进行新板端视觉切换时，旧相机/统计通道会停止；快档不绕过相机、流身份或位流资产核验。金属和塑料的新速度实物试跑仍待可用且匹配的视觉接口恢复，不能用旧位流或离线预算冒充新链路验收。
