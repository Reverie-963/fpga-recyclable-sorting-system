# 按识别位置一次计算完整抓放路线

2026-10-30后续新增[统一三类、平面全角度与多件批次入口](sorting_unified.md)，使用 `-Unified`；本页保留此前已实抓的奶盒位置/±30度入口与证据。新批次和更广角度尚不能引用此前单奶盒成绩作为实物验收。

`src.sorting_position_plan.compile_position_route` 接收当前抓点的纸卡毫米坐标、物体主轴方向和明确的控制模型，一次编译接近、腕角、下降、闭爪、抬升、转正、分类投放及回中位全部指令。它不打开相机或串口。当前只支持同一65毫米奶盒，其他类别/高度明确拒绝，不自动套用纸盒模型。

识别后的理想流程为：稳定三帧 → 掩码内抓点及方向 → 相机射线转毫米坐标 → 控制映射及底座/腕角 → 完整路线与插值检查 → 一轮执行 → 新鲜三帧复查。多段运动仍有必要，但不需要人逐段输入坐标或批准指令。

## 已实现的计算

调用：`compile_position_route(config, 'paper', card_xy, axis_deg, model)`。

- 原物高对应的纸卡到抓取映射得到名义XY，再应用模型中明确的径向补偿。
- 由目标方位计算底座PWM，由物体主轴与底座方位一起计算腕部PWM；物体旋转180度采用同一夹持方向。
- 编译完整源区接近/抓取/抬升路径，在正前高位恢复原腕角，再衔接原样件已测的纸箱转运、释放和退回路径。
- 第一条动作之前检查所有逆解、协议范围、指令时间、每段101点名义高度及最终中位张爪。目标不可达时不返回一段可执行的残缺路径。

模型字段为 `kind: carton-position-model-preview-v1`、`base_center_pwm`、`base_pwm_per_degree`、`radial_bias_mm` 和 `wrist_pwm_per_degree`。角度单位度、径向补偿毫米、舵机量PWM。必须记录来源，单点推断或左右对称假设不能伪装为全工作区实测标定。

库返回 `execution_permitted: false`、`robot_mapping_is_measured: false` 及是否处于旧点域，计算结果本身不授予动作许可。后续已新增下述明确的受监督执行适配；原资格记录不因候选逆解成功而改变。

因此“能一次算完”与“任意新位置可可靠抓取”是两个验收项。后者仍需覆盖左/中/右、近/远的多点控制标定、独立检查点、腕角及完整携物路径验证。后续应在经过验证的范围内直接按识别结果整轮执行；不应把一次成功点周围任意扩为已测面域。

## 统一入口的受监督位置模式

`sorting_position_controller.py` 将计算器接入原控制状态机，沿用相机内参、固定标记定位、原毫米登记、箱区、共享账本/设备独占、每条动作画面检查和串口回显/等待。启用后无需再次摆棋盘或重做九点坐标建系；模型参数与已有坐标登记的残差/机械偏置校正分别保留。

本机激活绑定中 `files.position_policy` 指向带哈希的 `operator-supervised-position-policy-v1`。它记录操作者明确许可、同一65毫米奶盒、名义试验点域、源区毫米多边形、小角度范围和模型参数，且明确 `workspace_physically_qualified: false`、`unattended_accepted: false`。控制器及计算器源码、此前实际21条任务、成功三帧/PL核验和原完整候选文件同时绑定，模型哈希必须相同。

当前试验中心范围纸卡X为−75～65、Y为0～45毫米；源物体完整轮廓另需落在既有登记投影得到的源区内。来源区域采用毫米多边形投影，不修改相机原图，不把旧小三角冒充完整工作区。原小三角与三类资格文件保持原样，点域外执行依据明确的受监督试验许可，不能称其已取得正式面域资格。

用户允许略转朝向后，现场稳定主轴约64.5度；本轮策略以原90度方向±30度为上限，原KnownItem资格的朝向窗口不改。位置与主轴共同决定腕角，所有21条先完整编译；逆解、尺寸、源区、空箱或范围不符均在动作前拒绝。当前位置试验采用5秒关节、2秒夹爪与释放后1秒停稳，原2秒帧龄、三帧和2%其他箱变化要求保留。

操作仍是根目录 `./tools/start_sorting_loop.ps1 -KnownItem -Mode Preflight`、`-Mode Preview`，现场就绪后 `-Mode Execute -Ready`；新绑定由原默认指针选择。Preflight返回 `route_mode: supervised_position_model`。Preview不打开串口、不改板端区域或基线；Execute才按新毫米源区绑定PL区域，并在中位动作前绑定准确原图基线，完整运行到退回后三帧核验。异常仍保存pending，不重发不确定动作。
