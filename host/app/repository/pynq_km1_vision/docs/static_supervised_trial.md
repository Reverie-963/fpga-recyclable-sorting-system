# 静态分拣受监督固定路径试验

`src.static_supervised_trial` 是独立现场试验入口。它执行操作者另行审核的关节指令文件，每段结束必须记录现场观察，再允许下一段。它不导入离线模拟器，不执行其符号计划，也不将模拟 `ok` 当作实物成功；不运行类别模型、视觉抓点、逆解、避障或自动视觉核验。与 PR #32 的关系是后续设备适配的独立基础，本入口本身不完成 #32 的在线集成。

首次现场结果见[2026-10-27 记录](../../docs/team/reviews/2026-10-27-static-supervised-trial.md)。正式机械臂配置、commissioned、位流及原有入口未变。

## 输入与运行

从 `pynq_km1_vision` 运行 `python -m src.static_supervised_trial --help`。必须提供 `--plan`、`--plan-sha256`、`--journal` 和 `--stage`；默认仅预演，不打开串口。`--execute --port <实际端口>` 才会执行，要求唯一 CH340 且与指定端口一致。每次只运行一段，没有自动重试。

计划是 UTF-8 JSON：`kind=supervised_fixed_path_trial_v1`、非空 `task_id` 和有序 `stages`。每段有唯一的英文小写下划线 `name`、非空现场核对条件 `observe`、非空 `steps`。每步包含完整协议 `command` 和整数 `duration_ms`。解析器检查关节 ID 0～5、不重复、PWM 500～2500、时长 1500～5000 ms 且与帧内时长相同。**这些是协议范围检查，不是本机机械限位或碰撞证明。** 路径必须在对应样件、工位及起始姿态下另行审核；没有随代码分发可直接驱动物体的通用计划。

执行阶段结束只记 `sent_pending_observation`；回显仅表示收到了相同字节。操作者根据真实观察调用同一入口，使用相同计划/哈希/日志目录/阶段，加 `--observe <观察内容> --ok` 记录允许继续的结果。异常观察不加 `--ok`。反馈不明确时保持停止；当前没有自动恢复、反向回退或紧急停止指令。

下一段要求之前所有段发送完成、计划及任务身份相同、现场观察为允许继续，且观察绑定的执行日志 SHA-256 完全一致。日志写入失败、部分发送、缺失完整回显或异常均停止后续命令；设备在退出时关闭。每段尝试在开串口前用独占文件持久记录，即使开串口失败也不自动重跑。

任务目录用 `active.lock` 排除同目录并发，崩溃遗留锁会阻止再次执行。锁和去重仅覆盖该任务日志目录；它们不能阻止其他控制程序或另建任务目录发送指令。现场须关闭其他控制程序，并保留原日志处理故障；不要删除锁、删除已尝试记录或换目录来绕过去重。不要把日志校验当作加密签名或可信位置反馈。

## 验证边界

本模块测试使用替身串口和时钟，覆盖缺回显、部分写入、开串口失败、已尝试阶段、观察缺失、日志变化以及计划哈希与重复关节错误。测试不打开设备。实物结论以对应日期、样件、路径和现场观察为准；示教路径成功不等于视觉自动闭环或三类成功率。
