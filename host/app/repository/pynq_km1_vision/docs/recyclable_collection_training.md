# 三类工位识别：按失败场景补数据

**后续用户要求完整最终方案，当前统一使用[最终训练方案与一键脚本](recyclables_final_training.md)。** 下文36格/126张路线保留为早期开发记录，不再作为下一轮正式训练流程。

2026-10-28。目标是用尽量少的有效图片完成“源区识别＋退离后的箱内复查”。当前三类共用一个 `can / plastic / cardboard` 分割模型；不为每个实物、每个箱子单独训练模型，也不采途中持物/脱落数据。

本方案是当前工位的采集预算和迭代方法，不是已证明的全局最优数量或精度保证。先跑已有模型，复用覆盖合格的旧数据，新增拍摄量按缺口扣减。所有新实物采集另按当次现场授权安排；本文件不启动相机或机械臂。

## 先做当前修复

现有箱内奶盒连续漏检。先复核已有录制图中的可见轮廓，用历史箱内正例、源区奶盒及空箱做小批针对性微调，并混合原三类训练图。最新加速轮次的三张末帧暂不进入训练，用于开发检查；同物体、同日场景不能当独立测试。

本轮已经准备的候选数据为162张训练、83张原验证；新增训练15张来自5组相关场景，不等于15种独立工况。所有新轮廓由助理查看原图及轮廓叠加图复核，保留标注方法；不宣称队长或独立人工已批准。最新箱内奶盒和身份尚未确认的塑料瓶仅做已知场景诊断。训练、权重和结果在本机 `local-only/bin-scene-finetune-20261028/`，候选不自动替换正式模型。

本轮实际完成11轮GPU微调后早停。候选best在未进训练的最新3张箱内奶盒图上均检出纸类，置信度0.878～0.888，和本轮助理轮廓的IoU约0.888；旧模型三张均漏检。但原验证中金属最高置信目标达标28→26、塑料15→20、纸类30→30，两张金属图出现同一目标的竞争类别，所以候选未通过逐类不退步门槛，正式模型保持原版。这说明应优先补充不同外观金属和箱内材料混淆场景，不能只看纸类改善就换模型。详见[本轮证据](../../docs/team/reviews/2026-10-28-bin-scene-finetune.md)。

## 其他材料如何处理

金属和塑料也必须检查箱内场景。先各取少量有代表性的真实图运行旧模型，正确且轮廓完整的姿态只做回归；优先标漏检、错类、轮廓不全、空箱误检的图。三类统一训练，避免每补一种材料就另建一个模型。

| 材料 | 优先覆盖的外观 | 主要核对项 |
| --- | --- | --- |
| 金属 | 罐身印刷面、银色面、横放、不同反光方向 | 反光区域是否漏入轮廓，箱沿是否误检为罐 |
| 塑料 | 透明瓶身、标签正反面、横放、瓶口/瓶底朝向 | 不能只标标签；要覆盖可见瓶身，检查透明边缘 |
| 纸类 | 正面、背面、侧面，横放和竖放 | 不能把固定纸箱或阴影当作待分拣目标 |

三个箱子是固定工位设施，不是三类待分拣物的标签。物体放错箱仍标真实材质：塑料瓶放纸类箱也标 plastic，不能标空背景或 cardboard。源区和箱内使用相同类别语义。

## 一轮126张有效图的采集预算

先给实物编号并确定集合，再拍摄。每类目标为2个训练实物、1个验证实物；另预留1个测试实物。已有实物和数据可以计入相应集合，但不能改变所属集合来凑数量。金属当前原训练集只有1个实物，尤其需要补不同实物；塑料和纸类也仍缺封存测试实物。

每个实物只保留12个代表姿态：源区4张、所属箱内8张。

| 图像用途 | 采法 | 有效图预算 |
| --- | --- | ---: |
| 训练实物 | 3类×2件×12姿态 | 72 |
| 验证实物 | 3类×1件×12姿态 | 36 |
| 空场景与错箱场景 | 训练12、验证6，见下表 | 18 |
| 首轮合计 | 复用旧数据、只补未覆盖格子 | 126 |
| 最终封存测试，另行采集 | 3类×1件×12姿态＋6个干扰场景 | 42 |

126张不是要求重新拍126张，也不是一次必须采齐。先用每类1个训练实物覆盖12格，共36格做体检；它们是126格的子集，已有合格图可以直接填格。优先标失败格，用首版候选辅助剩余轮廓，再决定补哪些实物与姿态。若暂时只有每类两个实物，先做开发修复，明确缺独立测试，不把相邻视频帧拆成验证或测试。

每个实物的12个格子：

- 源区4张：工作区中间/边缘各取两个实际允许的方向。位置须处于已核对区域；这里只收集视觉，不把拍到的位置认定为可抓。
- 箱内8张：中心/靠边两个位置，各取正面顺长轴、正面横放、背面横放、侧面四种姿态。圆柱瓶罐对应转动到不同印刷/反光面；不为凑姿态强行变形或放在不可见位置。
- 每摆一姿态先停稳，采3帧用于检查清晰度和稳定性；训练只选1张。相邻帧保留在同组，不能算三个独立姿态。

干扰场景18张：

| 集合 | 空场景 | 错箱场景 | 小计 |
| --- | ---: | ---: | ---: |
| 训练 | 6：三个空箱各2种自然照明/阴影状态 | 6：每类训练实物各2种错箱摆放 | 12 |
| 验证 | 3：三个空箱各1种 | 3：每类验证实物各1种错箱摆放 | 6 |

错箱场景是“当前目标箱不应判为目标已正确入箱”的负例，同时仍有真实材质的正标签。画面中所有待分拣目标都要标；空标签只用于确定没有任何待分拣物的画面。

固定相机、分辨率、底座与箱位。换实物和物体姿态，不靠移动相机制造多样性。照明采用预计实际运行的自然变化；若改变机位或箱位，记录新工位版本并重新核对标定。无需为了采图执行一轮完整机械抓放，静态手工摆放也可收集视觉数据，但不能计作机械成功。

## 标注与训练怎样省时间

1. 先让旧模型出轮廓，只修错边界；完全漏检时手工沿真实可见边缘补多边形。箱内小硬纸盒通常顶点较少；透明瓶和反光罐优先细查，不用检测矩形代替轮廓。
2. 先看每个场景1张轮廓叠加图；抽检全部不同实物及失败类型。相邻帧可辅助传播轮廓，但必须检查位移和边界，每张有自己图像哈希与标签。
3. 去除模糊、近似重复或不可判定图片。保存 `object_id`、真实采集场次、工位版本、来源和哈希。把待复核标签留在候选区，不直接投入训练。
4. 复用当前best微调，保留全部原三类训练图；第一轮先用640输入、batch=8、12轮上限、较小学习率0.0003、早停5轮，采用本机已跑通的ROCm原生后端。这是本轮起始参数，后续依据开发验证调整，不承诺固定轮数即可解决。
5. 每轮只比较旧模型、候选best和last。固定阈值，分别查看源区、箱内、空箱、错箱，以及三类原验证回归。保存失败图，下轮每个失败类型先补5～10个有差异场景，不重复堆已经稳定的姿态。

原83张验证被多次用于开发选模，不是封存测试。训练/验证/测试按实物和真实场次隔开，增强只用于训练；旋转或颜色增强不能补出新实物的背面纹理与真实透明/反光边界。官方方法参考：[数据划分与预处理](https://docs.ultralytics.com/guides/preprocessing-annotated-data/)、[训练增强](https://docs.ultralytics.com/guides/yolo-data-augmentation/)。继续使用本机已安装版本，不为本轮实验升级模型或库。

## 决定是否换模型

固定比较类别、完整轮廓IoU和置信门槛；按场景组报告，不能把连续三帧当三次独立成功。本轮开发检查要求最新奶盒源区与箱内三帧均有高置信且轮廓匹配的目标、非奶盒箱区不能误放行，原三类验证的逐类最高置信正确轮廓数量不下降。满足这些仍只证明开发候选有改善，正式部署需后续新场景验收。

放置后仍同时核对源区清空、正确箱内同类目标和持续新增外观；轮廓模型改善不等于整个终态核验已经通过。结果不明确则人工复核、暂停下一件，不自动重抓。NPU和自动持物/脱落判断不在当前范围。

最终冻结模型、阈值和输入方式后，再用未参加训练与调参的测试实物/场次验收。记录误检、漏检、错类、轮廓和整轮人工真值，区分识别与机械问题。测试结果若用于改模型，该批数据以后属于开发数据，另补封存测试。
