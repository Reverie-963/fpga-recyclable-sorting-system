接线：相机/USB集线器接PYNQ USB Host；PYNQ以太网连接AI PC；PYNQ通过独立USB串口适配器连接KM1/ESP32，语音模块USB另接PS。PC保留本地显示、推理与数据转发。详见报告原接线图与接口文档，照片由队伍补齐后放入预留目录。

PYNQ、AI PC和机械执行器分别使用匹配的原电源。电源适配器电压、电流、极性、舵机供电与功率铭牌此次未独立读回，提交前拍摄并填实，不能用芯片功耗估计代替整机输入功耗。不改引脚/XDC、线路、电压或控制器固件。厂商标准机械结构不是自制PCB；自制部分主要为算法、HLS核、上层/PS控制与工位集成。

当前照片方位说明以本次队伍现场确认：正面图左后大箱纸盒、右后大箱塑料、左前小箱金属罐。它与俯视图方向不同，不能依拍摄者左右推断软件路由。源区为标定纸及其右侧已登记取物区域，不是前方整片灰垫。
