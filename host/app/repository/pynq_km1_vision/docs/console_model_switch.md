## 识别切换与动作范围

8830是现有8810/PYNQ中控前的显示与选择层；不重启原代理或PS服务，不迁移原账本，不改串口、速度、标定、投放区或执行资格。现役执行仍绑定YOLOE26。其他选择可实时看类别和轮廓、上传图片；此入口的预演/start/arm/voice_arm返回409，需切回执行绑定模型后使用原动作流程。stop、heartbeat、cancel以及原复核/重置流程继续交给PS，保留原owner/token/请求号检查，没有控制响应重发或PC机械回退。

其他独立网页/CLI/语音入口仍由原PS控制，使用其原绑定模型；选择层不代替PS全局控制权。切换为识别对比不代表其他类别或模型获得机械资格，也不改变已有blocked状态。视觉通过不代表完整实抓验收。
