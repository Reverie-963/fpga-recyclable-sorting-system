# 一页引导采图与三类资料复用

把“拍15张照片、手工整理名单、再量五组坐标”改成一页操作：先核对三类已有实物证据，自动筛选历史棋盘图作为镜头拟合候选，再在棋盘停稳时自动收录有效照片；计算通过后，同画面识别固定标记与已复位旧棋盘，自动提取20组坐标登记，最后做换机位检查。

机械臂不参与本页操作，不打开串口，不切换模型、PL或生产配置。相机通过已有`127.0.0.1:8780/frame.jpg`只读桥接读取，不另外打开板端相机，不使用浏览器摄像头权限。默认不开始采集。实际照片与登记完成前不能说新自动定位已实物通过。

## 启动与操作

仓库根目录：

```powershell
.\tools\start_station_calibration.ps1 -SessionRoot local-only/yoloe-physical-loop/physical-20261029-131343
```

日期目录是本次复现示例；其他工作站使用自己的实际联调记录目录。启动器新建输出目录，审核并冻结已有三类资料，再运行本机8782引导页。已有相机桥接保持运行；若不存在，本页显示画面不可用，不猜测凭据或启动新的板端连接。

打开 `http://127.0.0.1:8782/`，操作集中在同一页面：

1. 看三类已复用信息，不重新示教抓点、夹爪和箱位。旧三件样品的监督闭环与任意新物品/无人值守验收保持原来区别。
2. 使用现有5×4内角点、20毫米格距棋盘。确认历史采集和现在是同一相机/分辨率/镜头对焦设置，才勾选历史照片复用；设置不确定可不勾选。
3. 点一次“开始自动拍照”。缓慢移动棋盘到画面左、右、上、下，前后左右倾斜约15～30度并改变远近，每种姿态停稳约一秒。页面显示角点、清晰度/停稳提示与计数，自动排除过于相似的姿态和模糊照片；无需逐张快门和命名。
4. 从10张拟合（含筛选通过的历史图）加3张新保留检查图起步。程序自动计算并检查覆盖、倾角、重投影和逐张留一稳定性。质量未通过时停止采集，先检查数据和镜头模型，不再笼统地反复要求补3张；有足够照片时可点击“重新计算现有照片”。
5. 打印并平整固定页面链接中的标记板，保持四枚标记的已知相对位置、实际尺寸；标记板和旧棋盘处在同一工作面，不垫高。恢复旧棋盘此前定位及方向，画面C2对应旧原点、D2朝旧卡右方、C1朝旧卡上方。若检测方向反了可切换180度。
6. 勾选实际尺寸与旧卡定位确认，点击“登记固定标记与旧坐标”。至少三枚固定标记和20个棋盘角点同时完整可见，停稳后自动保存三张独立原图。由固定标记估计机位，自动读取20组旧卡/工位对应点，12组拟合、8组检查，不必再用尺录入五组位置。首次仍需恢复旧原点，程序不会凭空找回被挪走且无定位依据的旧卡。
7. 标记板、棋盘、底座和箱子不动，只移动相机，停稳后点击“换机位坐标检查”。最大坐标差须≤1.5毫米；拒绝时保留原登记，不偷偷重写坐标掩盖误差。这只是本次坐标一致性检查，不是机器人定位精度。

原图按桥接JPEG字节保存，叠加点/文字只出现在预览上；同时保存原图哈希、解码BGR哈希、帧号、流ID和年龄。保留检查照片不加入拟合。暂停保留已保存照片；相机流重启自动停止收录，需要核对设置并新建会话。

## 三类资料怎样复用

`src.station_history` 将既有材料转换成只读历史档案，核对计划哈希、完整执行日志、指令与实际写出字节、完整回显、阶段起点连续性、最终视觉报告和操作者反馈绑定。保留纸盒/金属/塑料各自高度、夹爪量、局部映射、已走过路径与目标箱，不把其转换成可直接执行的新计划。

53毫米塑料档案根据其已经完成的19条闭环、当次接近计划绑定的物面/低位/悬停映射导入，不再当作尚未标定，也不是仅凭高度接近而复制56毫米罐的配置。单件监督结果不会自动打开正式质量或无人值守标志。

相机内参可以利用**不同机位的照片**，前提是相机/镜头设置相同；相机位置本身是每张照片各自估计的量。机械臂/图像平面映射仍按高度和机位分别保存，不能跨机位混用。当前找到7张独立历史图候选，去除相似姿态后有2张可用于进一步筛选；只作照片候选，还需用户确认镜头设置。不要把7张相似正拍都当作7种有效姿态。

按当前两个可用历史姿态估算，起步需要新增8张拟合+3张保留检查，共11张自动抓拍；实际是否足够由检查决定，不承诺固定总张数或拍摄分钟数。省去的主要工作还包括三类重复示教、逐张快门与命名、手填照片列表，以及五组坐标尺量录入。

## 镜头模型与恢复已有照片

低分辨率5×4角点引导采集默认使用`calibration_model=brown4`：保留k1/k2径向项和p1/p2切向项，显式固定三阶径向项k3=0（OpenCV `CALIB_FIX_K3`）。CLI不指定时仍使用原`brown5`。所有留一重拟合使用相同模型，覆盖、倾角、拟合/检查误差及稳定性门槛不变；不删除难图或将保留检查照片转入训练来通过检查。具体本轮模型比较与原图证据见[修复记录](../../docs/team/reviews/2026-10-29-guided-calibration-reuse.md)。

若进程需要更新，可用相同的`--history`、`--station`、`--output`加`--resume`恢复会话。程序核对历史包、标记配置、相机地址、照片哈希、镜头身份和原split，恢复全部已收录照片，保持暂停；原图和旧manifest不覆盖，新模型计算另存带哈希的manifest。已有`camera.json`时恢复结果和后续登记步骤，不重新要求拍摄。相机重新启动或设置变化仍须另外核对，恢复照片不代表镜头设置自动相同。

## 登记后只看固定标记自动恢复机位

`world-registration.json`保存后，引导助手自动启用`FixedMarkerTracker`。正常换位无需按钮或旧棋盘；只保留固定标记板与机械臂底座的相对位置，至少三枚标记完整入镜。每次要求三张独立新帧、同一流、帧号递增；静止质量检查通过后提供当前机位。机位移动、标记不足、图像过期或相机连接失败会立即撤销可用结果，停稳后重新计算；流号改变需要核对相机设置并恢复助手，不能静默沿用。

新鲜度将源帧年龄与本机等待时间相加，超过1500毫秒不再返回有效姿态。`GET /localization`以及`/state`中的`localization`提供图像/帧/流绑定、相机/工位/旧坐标桥哈希、三帧证据和三类已检查点域投影；结果始终`automatic_motion_allowed=false`、`production_integrated=false`。不是可执行计划。初次恢复或标记投影变化超过1像素后另存三帧原图与`relocate-*.json`，不中途重写原登记。未移动时保持同一generation，具体pose仍绑定每一张新帧。

三类预览按各自53/56/65毫米高度，将原抓取与悬停检查多边形取交集，再投影到当前相机；名义机械映射只读复用，不使用旧像素单应矩阵。原点域的顶点及中心在对应高度也加入≤1毫米的三帧两两坐标稳定性检查。投影/反投影往返仅是算术一致性，不能作为独立物理误差。预览在原点域之外仍不允许抓取；如果原点域不在工位模板`work_polygon_world_xy_mm`内，会显式标记`inside_declared_work_polygon=false`，保持正式拾取守卫拒绝，不擅自扩大工作区。

页面新增自动定位状态，以及换机位检查的明确进行中/成功毫米差提示。重启恢复已有登记和匹配原登记哈希的上次检查，但实时机位必须重新读取三帧，不恢复旧帧的ready状态。原“换机位坐标检查”按钮保留作有旧棋盘时的独立复查，日常换位不必点击。

8782页面保持只读自动定位与三类映射预览；正式单件入口现已[接入新坐标](sorting_relocated_grasp.md)，包含实际工作区、箱区、识别抓点、视觉基线及执行期机位检查。新入口预检和只读板端核对通过，尚未在本轮执行新坐标下抓放；本页ready不代替实物抓取验收，也不能从原固定像素入口绕过新工位绑定。

## 输出与边界

静止标记登记使用三帧共同可见的至少三枚标记：相互角点移动≤0.5像素、机位旋转差≤0.5度，并在工作域四角及中心、声明高度上下限上检查所有单帧及均值机位的两两坐标差≤1毫米。通过后以标记角点均值估计机位，仍保留原0.8/1.5像素重投影和多解检查。这样避免小标记平面姿态的旋转/平移耦合噪声被直接当成相机移动；旧默认定位仍保留相机中心差≤2毫米检查。此分支只用于静止登记，不提供运动许可。登记的旧原点、方向、打印尺寸仍需操作者实际确认，预览通过不能代填这些声明。

输出包含三类历史包/原始JSON快照、候选照片、采集原图及元数据、`events.jsonl`、镜头档案、三帧登记照片、对应点、坐标登记与换机位差异。目录必须新建，不覆盖旧证据。文件全在本机；没有共享地址时不能宣称已经同步给队友。

8782本页不驱动机械；正式单件入口通过单独绑定的工位档案使用新坐标，原配置与机器人映射保持。高度后续仍由用户给定，已有机器人档案仅适用于各自实测样件和点域。新相机需要自身镜头档案；固定标记和机器人底座发生相对移动时需要重新核对工位登记。

几何接口、打印尺寸和备用手工流程见[自动恢复机位与人工高度](station_camera_relocation.md)。
