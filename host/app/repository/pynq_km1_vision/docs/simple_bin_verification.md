# 简易箱内检查

2026-11-01整批流程更新：先从实际取物工作区的初始登记画面，计算全部选中目标的抓点、顺序、夹爪和完整路线，冻结并落盘后才开始第一件。任何目标无法规划、需要占用检查的落点冲突或超过本批件数上限，整批在动作前拒绝。首动前仍用新鲜画面复核整批尺寸/身份与现场；后续按冻结队列执行，不重新识别选件、不重新计算下一件路线。相机流/新鲜PNG/固定标记、执行身份、停止、真实心跳、独占权及串口回显/完整等待仍检查，异常立即中断并保留待复核。全部路线完成后，只采一张新鲜识别画面对访问过的箱统一核验。此更新取代下方旧记录中“下一件重新观测规划”的行为。

报告新增`batch_planning_mode=initial_scene_all_routes_before_motion`、`planning_completed_before_motion`、`planned_count`和`frozen_plan`；预演的`batch_preview.frozen_plan`包含整批命令。只处理开始时登记且符合材质筛选的工作区目标，不将后来放入的物体加入队列。最多6件/1200秒；超限不先执行前6件。空箱检查启用时预留各落点；明确关闭时沿用允许共享的既有固定落点，不新增放置路线。终检仍仅证明所访箱占用，不证明逐件成功或源区清空。未完成全部路线时不做批末成功核验、不重试。

2026-10-31 队长要求降低当前单件分拣的终态验收门槛：“里面有东西就行”。现役 prompted 控制台默认使用 `placement_verification.mode = bin_occupied`。

机械臂完成整条动作并退回后，读取一张新鲜画面。目标箱满足以下任意一项就记为简易通过：

- 任意类别的检测置信度至少 0.20，且至少一半检测掩码落在目标箱 ROI 内；可以是原有物品，不要求与抓取类别相同。
- 即使模型没有检测结果，目标箱相对**本轮动作前画面**有明显变化：BGR 三通道绝对差之和大于 45，最大相连变化块至少 64 像素。

不要求唯一新增实例、同类别/原始标签、原样件面积、指定落点的 95% 包含、源区消失、其他箱不变、三帧持续匹配或完整 PL 终态差分核验。RGB 比较先沿用固定标记的亮度调整；旧空箱参考图不作本检查的比较基准，避免箱壁位置差异误报。RGB 分支仅提供箱内可见变化证据，不能保证变化一定来自物品；阴影也可能触发。完全没有新变化且模型漏检的已有物品仍可能需要复核。

配置在 `config/prompted_motion_policy.json`。`rgb_difference_threshold`、`min_component_px`、`min_detection_confidence` 可配置并经过类型/范围检查。无 `placement_verification` 配置的旧入口默认 `semantic_rgb`，保留原核验。缺少明确批末说明时，简易模式与 `end_of_batch` 同配仍在动作前拒绝。

2026-10-31用户明确要求当前已登记的一批一次发令、动作全部完成后统一核验。`automatic_batch_enabled=true`及独立`batch_final_operator_statement`使提示模型入口采用`end_of_batch`、`skip_per_item_visual_verification=true`。逐件动作之间保留新鲜定位/高度和动作前检查，取消逐件结果核验；最后只采一张新鲜同帧识别图，对每个已访问箱按上方同一占用规则核对一次，同一箱接收多件也只查一次。RGB基准为本批第一件动作前画面，报告`scope=visited_bin_occupancy_only`，继续不证明每一件都已入箱或源区已清空。

首次观测会固定实例账本，初始选中目标须全部能规划才开始；默认最多6件、1200秒，仅执行本次登记池及材质筛选，不自动接收后来物体，不重抓已尝试目标。执行必须有逐件高度登记。停止、真实客户端保活丢失、未知回执和运动失败仍立即中断，保留单件及批次未决记录；旧失败不改写、不自动重放。该功能的三件连续动作与单帧终检已作模拟验证，不能作为实物整批成功验收。

报告 `verification.status = bin_occupied_pass`，记录 `basis`、比较基准帧、目标箱、检测结果与像素统计；`class_verified`、`new_item_verified`、`source_removal_verified`、`physical_success_verified` 均为 false。外层沿用原 `completed_visual_evidence` 完成状态供控制台和独占权管理识别，必须结合报告内模式理解，不能称为原严格验收、无人值守或生产质量通过。

采图身份/哈希/时效、固定标记、动作中保护、机械可达性、停止、独占权、串口错误和旧未决任务仍照常处理。简易通过后记录本次目标已尝试，防止同批再次抓取；下一件动作前仍需重新观测。既有失败报告不会回写成成功，部署不会清除旧 pending 或自动发送动作。

验证命令：工程目录 `python -m unittest sim.test_bin_occupancy sim.test_runtime_admission sim.test_sorting_unified -q`。集成夹具未同步的独立检出会明确跳过相关测试；纯图像判断和配置测试仍运行。
