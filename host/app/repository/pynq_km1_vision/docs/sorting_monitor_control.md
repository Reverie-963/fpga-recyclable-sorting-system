## 使用

1. 可先点击“预演检查”，只采图、识别、计算计划并保存预演记录，不打开机械串口、不切换板端区域或重设基线。
2. 实际动作前勾选本轮现场就绪：已测样件、目标箱为空、中位张爪、人员在场，放物后立即撤手。存在未决任务、停止文件、设备占用或绑定不符时无法执行。
3. “分拣一次”立即尝试处理当前一件；“开启待命”先观察取物区为空，再等待放入一件稳定目标。已有物体时提示先移走，不能直接触发。目标稳定与抓取条件由原执行器逐帧检查。
4. 待命最长120秒。每次开启只授予一次实际尝试，失败也不重试、不排队；结束后退出，需再次核对现场。当前不支持连续多件、箱内堆放或无人值守。系统没有新增自动撤手判定。
5. “退出待命”取消等待，保留原停止文件不变。“停止分拣”写入原全局停止文件，执行器在动作守卫和等待中检查；已下发的运动可能仍需结束，不属于硬件急停。新版“重置状态”只在任务结束及现场确认后归档处理停止/pending，运行中或设备仍被占用时不能重置。

同一时刻页面只接受一个操作；多标签页不能接管另一页的心跳。刷新、关闭或断连后约12秒未收到操作页心跳即退出待命，实际执行中则请求停止。服务重新启动默认未待命，不恢复原操作。只读查看页面不续期另一页的待命。

默认启动命令仍为仓库根目录 `./tools/start_sorting_monitor.ps1`，默认端口8779。2026-10-30升级时现有8779服务保留，新版验证服务使用 `./tools/start_sorting_monitor.ps1 -Port 8786`，访问 <http://127.0.0.1:8786/>。旧8779进程需要正常退出后重新启动才能支持新增控制API；仅刷新旧服务页面不能升级后端。

仅监听127.0.0.1，尚未开放手机或局域网远程控制。识别模型仍复用8778；启动页面不会加载模型、连接机械串口或自动开启待命。

后端从 `local-only/station-grasp-integration/active.json` 解析并校验当前绑定，固定本次服务的绑定指纹与停止文件路径。绑定源文件变化、前次任务未决等保持阻断，不能通过勾选就绪提升资格。缺失控制配置时仍可查看原监视内容，补齐后重启监视服务。配置、令牌、停止文件和完整物理记录不回传浏览器。

## 接口与记录

- `GET /operation`：操作状态、阻断项、操作号、页所有者、最近结果摘要、待命剩余时间及本次进程令牌。GET不执行动作、不续期。
- `POST /operation`：最多2048字节JSON，Host/Origin限本机服务，校验进程令牌。字段为 `token`、`owner`、`action`；preview/start/arm另需唯一 `request_id` 和 `material`，start/arm还需布尔 `ready=true`。heartbeat需匹配 `operation_id` 与owner。动作仅允许preview/start/arm/cancel/stop/heartbeat，不能传入串口指令、配置路径或机器人坐标。
- `POST /operation` 的 `action=reset`：同样要求唯一request_id；持久保护存在时必须 `reset_confirmed=true`，代表页面明确的现场确认。结果为state_reset，原失败不改写；返回新的idle状态，未自动待命或抓取。GET新增reset_supported/reset_requires_confirmation。重置不接受自定义文件路径或机器人指令。
- `POST /operation` 的 `action=home`：唯一request_id，另需home_confirmed=true；独立实际动作，不使用“目标箱为空”的ready作为回位确认。结果neutral_return_command_completed表示完整回显/等待，不声明角度读回。GET的home_supported表明该后端支持入口；未知姿态、未决任务或设备占用仍拒绝。预演和重置不会转为home。
- 状态：idle、checking_preview、checking、waiting_clear、standby、executing、stopping、stopped、finished、rejected。finished只表示入口结束，实际结论取result.status与原任务账本；预演不计实物成功。
- 一个服务进程记录已接收的request_id，重复请求拒绝；最多1000次后需重启，不驱逐旧编号以重新接受重放。
- 页面事件保存到 `local-only/monitor-operations/events.jsonl`，只有操作与结果摘要。实际任务沿用原物理账本；预演独立保存在绑定目录的dashboard-preview-ledger，避免混入语音预演。共享适配器新增 `transport=local_dashboard`，原语音默认asrpro_usb_uart0，报告voice_transport据实际入口记录。
