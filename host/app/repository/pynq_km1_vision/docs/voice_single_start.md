# 语音单次启动与停止

2026-11-01范围修正：自动匹配仅覆盖绑定的实际取物区，不采用源区与箱区的外接矩形。区外/箱内识别不要求档案，仍保留障碍轮廓；源区其他材质邻物仍须登记。页面、语音和PS的区域策略已同步，当前仅吸管需10mm高度，右侧罐/重叠瓶识别不入池。既有待复核/STOP不会因缩小尺寸范围而自动解除。详见[本轮记录](../../docs/team/reviews/2026-11-01-pickup-source-only.md)。

## 尺寸库自动匹配后整批启动（2026-11-01，当前8843入口）

当前默认：人员在场、手已撤出后，明确说现有分拣口令，语音会为当前源区物品匹配尺寸库，不必先点页面保存。AUTO处理初始当前整批，材质口令选择其中目标材质，末尾统一核验；不会开始下一批或自动补抓。即使只分一种材质，其他源区邻物也须有可匹配尺寸供避让使用。页面明确保存的临时登记仍可单次使用，优先于库匹配；下文页面登记段落是兼容流程，其“一次只执行一件”已被当前整批模式取代。

PC从现有相机接口取新无损PNG并核对解码像素哈希，在当前执行模型上做同帧图像识别和箱区投影；匹配沿用页面同模型/同材质/外观与形状阈值，无唯一档案则拒绝，不以材料默认高度或细分类名猜尺寸。板端收到完整当次`height_plan`后，经原`register_heights`验证和一次性登记再只发一个start。所有相机流/模型版本/掩码IoU、动作前复核、所有权、保活、STOP、pending及未知回执保护保留。尺寸服务不会代发操作或心跳。

本机18943仅回环，现有SSH反向链路转发同端口至PC，`Authorization: Bearer <现有控制凭据>`校验。唯一POST `/prepare`字段为`{request_id, material, profile_sha256, revision}`，最多1024字节，每个请求号只处理一次且不排队；回复携带对应请求号/配置身份、`height_plan`、库revision、源帧号、布局哈希及`physical_request_sent=false`。GET `/health`同样需鉴权。返回尺寸不是授权或位置反馈；执行仍由PS完成当前帧匹配与准入。服务由8810代理托管，8843与语音共读同一本机库，不从8842中转，不对公网开放。

新语音包独立冻结于`/opt/km1/voice/console-library-20261101-v1`，原主控制服务未替换。`tools/board_voice_service.py`默认只检查，启动器在原服务可用后检查/空闲恢复语音，启动不会发动作。更多操作显示“语音已连接 · 自动匹配尺寸库”；缺尺寸历史档案须先在页面明确选用并保存当前外观后才自动匹配。现有六口令及封闭回复不变，不声称新增了模型切换、档案编辑或复位口令。

整批结果读取核对aggregate、原batch、全部物理子报告哈希及末尾核验文件。当前简易占用只证实访问箱有物，语音投影为需要复核，不拿它或混合材质最后一件的成功片段冒充整批成功。原始报告不改写。实现、200项专项与现场无动作读回见[本轮记录](../../docs/team/reviews/2026-11-01-voice-console-library-alignment.md)；真人语音和扬声器尚未验证。

## 页面登记高度后语音启动（2026-10-31更新）

8842先点击“登记”，按编号填写取物区每件物品桌面到顶部的高度，核对“人员在场，手已撤出”，再点击“保存高度，供语音启动”。随后先说“小爱同学”，听到唤醒回复后说“自动分拣”“金属分拣”“纸类分拣”或“塑料分拣”。保存仅登记参数，不触发机械动作；预演仍可单独执行。保存后输入锁定，修改时重新登记会先撤销旧登记。

PS保存完整逐件`height_plan`、当前执行配置哈希/版本和独立登记ID。登记保存在本次服务内存中，5分钟有效、不跨重启；语音只提交该ID，不再读取旧的单一高度或回退到材质默认高度。缺少登记时在发出开始请求前拒绝，不新增STOP。即使指定某材质，源区邻物也需登记高度用于投影与避让。

接受一次start后即消费登记（包括手动start）；停止、取消、回初始、重置和模型切换使登记失效。预演不消费登记。请求已接受但回执异常仍保持消费状态，不能回滚为可再次执行；提交后回执不明继续沿原停止保护处理，不自动重发。登记期间不持续运动、不启动自动循环；一次口令仍执行一件，结束后重新登记剩余物品。

保存时核对页端会话、空闲/阻断状态、现场确认和模型/配置；启动时再次核对登记ID与模型版本，并复用已有逐件匹配、相机会话、掩码IoU、完整路线和动作前全源区检查。位置移动、漏填、同类歧义或相机变化不能借用旧高度。输入物高仍只用于坐标投影，不修改机械`grasp_z_mm`。

接口新增`/operation`动作`register_heights`与`clear_heights`。前者携带`height_plan`、`ready=true`、`request_id`及可选当前`height_registration_id`；后者携带准确当前登记ID。新语音start只带`height_registration_id`及原模型身份/单次请求字段，不能同时带高度。状态提供`voice_height_registration_supported`、登记摘要（ID、配置版本、剩余秒数、编号/高度）、会话和单调版本号，避免旧显示缓存覆盖刚收到的保存/撤销回执。完整掩码仅在PS保存及任务证据中保留，不每次轮询传回。

实现、验证和上线边界见[本轮记录](../../docs/team/reviews/2026-10-31-voice-height-registration.md)。以下为之前语音单次启动的历史说明，其中“沿用当前物体高度/材质默认高度”已由本节取代。

2026-10-31，用户明确要求接入语音启动。板端ASRPRO的AUTO/PAPER/METAL/PLASTIC口令进入和页面相同的单件 `start` 流程，不再被旧 `current_trial_requires_single_manual_attempt` 规则一律拒绝。

每次口令生成唯一请求号，只发送一次开始请求。提交前读取当前PS执行绑定，携带 `execution_profile_sha256`、`execution_binding_revision`，由PS核对。旧版曾沿用单一高度或材质默认值；新版改用上节页面登记。仍使用已有动作、速度、首条前检查与终态核验，不自动连续抓取、重试或回中位。

旧实现把本地策略拒绝当作执行异常，随后写入STOP，导致未启动也锁住工位。现在通过明确的 `VoiceCommandNotSubmitted` 类型区分：

| 情况 | 行为 |
|---|---|
| 提交前状态不可读、已有阻断或执行绑定缺失 | 提示拒绝并记录 `interface_rejected_before_submission`，不提交开始、不新增STOP |
| PS明确HTTP拒绝，未授予本次控制权 | 沿用原拒绝/BUSY处理，不停止其他会话 |
| 开始请求已提交但回执不明 | 不重试，保留停止保护 |
| 已接受任务后的通信/身份/保活异常 | 保留停止保护 |
| 明确停止口令 | 持久化STOP并停止同一控制流程 |

只在初次派发位置捕获上述明确类型；同样的错误文字、或任务接受后出现的该类型，不视为“肯定没启动”。启动前的只读失败也不会误归类成未知的动作回执。

现有主动停止及待复核记录不会因升级、重新说启动或模型切换自动清除；继续使用8842设置里的现场确认及状态重置。语音停止继续可用，不能将“接入语音启动”理解为忽略停止或未决保护。

部署阶段可配置 `voice_bootstrap: {path, sha256}`，路径必须在阶段根目录内且哈希与 `remote_sha256` 一致；没有该字段的阶段保留原启动方式。现役采用已校验的语音扩展，只替换语音进程，保留原PS主机、冻结原源码、模型和权威状态。部署和测试边界见[本轮记录](../../docs/team/reviews/2026-10-31-voice-single-start.md)。
