# 三类已测样件：统一单件自动入口

当前现役入口已[直接接入新FPGA视觉](sorting_station_interface.md)，不再调用旧双核远程统计；抓点及语义掩码统计明确在PC计算。队长后续将源区及箱内类别置信度门槛改为0.7，保留三帧和其他保护。金属/塑料快档已实际执行44.234/36.547秒，均获操作者确认；塑料在0.7下另做只读三帧重查通过，原试验失败记录保留。

2026-10-29视觉链路切换后：下述实物成绩属于旧双核统计链路。当前已启用独立板端RGB/六区视觉核验，新位流不含旧几何核；旧执行入口受迁移标记保护，不能直接使用下述Execute命令驱动机械。需先适配新视觉接口并重新验证，原验收记录保留。见[新视觉部署状态](station_board_vision.md)。

2026-10-29新增[三类闭环快档](sorting_motion_speed.md)：按距离计时并合并可删中间点，奶盒一次真实14条/29.703秒，操作者反馈无问题；末端原有塑料件掩码稳定性核验未过，人工复核记录保留。其余两类当前仅有快档回放预算。使用 `-MotionProfile compact` 明确选择受监督快档，`qualified`可回退原低速；不是三类新速度完整验收。

该入口面向本轮已经过现场核对的同一奶盒、空易拉罐和透明塑料件。一次启动自动完成识别选类、抓点计算、夹取、按类入箱、退回及三帧复查，中途不需要逐段确认。每次只允许一件、目标箱为空、操作者在场；它不提升原生产入口的识别质量、机械硬限位或无人值守验收状态。

当前现场使用YOLOv8s-seg/ROCm，PYNQ采图与双核统计，AI PC调度并USB直连KM1。权重、运行指纹、图像标定、已执行的关节路径和操作者实物反馈分别绑定。换模型不能静默沿用原指纹；修改样件高度、抓取参数或路径后，旧资格记录会失效。实际阶段与限制见[实物记录](../../docs/team/reviews/2026-10-29-physical-loop-commissioning.md)。

2026-10-29当前统一入口三类各一轮已现场完成：纸盒16条/88.625秒，金属罐18条/99.860秒，塑料件17条/94.265秒。三帧核验和操作者反馈全部通过，最终工程回归485项通过。时间包含当前低速动作和视觉核验，不是生产吞吐承诺。

## 本机操作

先保持相机、工作垫、机械臂底座和箱子固定。机械臂应在已核对的中位张爪状态。`-Ready`表示本次启动时操作者已确认：放入的是已测样件、目标箱为空、手已退出活动区、中位张爪。它不写入生产验收标志。

首次使用当前机位的空箱基准时，三个箱子均清空，将一件已测样件放在源区，再运行：

```powershell
.\tools\start_sorting_loop.ps1 -KnownItem -Mode Preflight
.\tools\start_sorting_loop.ps1 -KnownItem -Mode CaptureEmpty -Ready
```

CaptureEmpty只采图、识别和保存无损基准，不连接机械臂。它要求三帧中三个箱子均没有识别物体、源区只有一个稳定目标，并再次核对固定标记；不得用占箱画面代替空箱基准。桥接重启后需要显式重新核对基准，不能自动接受新流。

移走大面积白色标定卡可能使自动曝光发生局部变化。显式CaptureEmpty在严格模板匹配未通过时，允许只读检查两处标记的双向光流：每处至少8个可靠角点、足够空间覆盖、亚像素位移及纹理对照均须通过，才保存新的实景模板。该步骤不移动或变换图像坐标，不修改抓取映射；执行中的0.98相关性和1像素位移界限保持原值。

每件物品放好、目标箱为空且手退出后：

```powershell
# 只看完整计划，不发送动作
.\tools\start_sorting_loop.ps1 -KnownItem -Mode Preview

# 执行一个自动周期，结束后回中位张爪
.\tools\start_sorting_loop.ps1 -KnownItem -Mode Execute -Ready
```

一轮结束后重新放下一件再启动。源区多件、低置信、形状或方向不符、抓点超出局部检查域、占箱、机位变化、图像过期、模型指纹变化均会拒绝。没有目标时不发送动作。目标箱内已有东西时先清空该箱，不支持在未经核对的堆高上继续投放。

本机配置为`config/sorting_known.local.json`，已被Git忽略。`config/sorting_known.example.json`是没有标定和资格记录的示例，只适合预检，不能执行：

```powershell
.\tools\start_sorting_loop.ps1 -KnownItem -Mode Preflight -Config pynq_km1_vision/config/sorting_known.example.json
```

## 分类与单位

| 类别字符串 | 箱位 | 样件物面高度 | 名义抓取模型Z | 现场最低爪端离桌 | 已用闭爪PWM |
|---|---|---:|---:|---:|---:|
| paper | 右下纸类箱 | 65毫米 | 50毫米 | 约60毫米 | 1500 |
| metal | 右上金属箱 | 56毫米 | 10毫米 | 约35毫米 | 1300 |
| plastic | 左侧塑料箱 | 53毫米 | 10毫米 | 约35毫米 | 1300 |

金属罐长150毫米，塑料件长120毫米。名义模型Z不等于实际离桌间隙。图像按各自物面转换到卡坐标，再分别使用悬停/低位机器人映射；只有抓取点在已检查局部域内才可规划，整件轮廓另外受源区、宽长和方向范围约束。卡面拟合误差不是机器人定位精度。

三件样品均横放，长轴沿画面上下，中心靠C2向TOP约5毫米处；不要求像素完全重合，入口会从当前轮廓内部计算检查域内的抓点。奶盒使用带绿色横条和大条码的窄面朝上、实际高度65毫米；营养表面朝上曾得到约0.63～0.74，在当时0.8门槛下拒绝。当前按队长新要求改为0.7，仍须三帧及形状、抓点等条件全部通过，不能把改阈值当作模型精度提升。

纸、金属、塑料分别使用已走过的右下、右上、左侧关节路径。每条后段命令在第一条动作前已完整编译并检查，不能把一个类别的箱位或高度当另一类默认值。当前低速关节指令为5秒，夹爪2秒，并保留停稳等待。

## 核验与停止

动作前至少三帧识别和PL几何对照；打开串口后第一条动作前再次观察源物体。机械臂遮挡源区以后不伪造手中识别，改为每条命令前检查固定标记位置和可见性。回中位后丢弃旧帧，重新采三帧，要求源物体消失、正确箱内唯一同类新实例持续出现、语义和RGB变化重合、其他箱与旧物保持不变，才记为`completed_visual_evidence`。

所有相机证据保存无损PNG，分别记录相机JPEG、解码BGR及模型请求PNG校验值。固定标记只允许有界整体曝光补偿，不对图像做几何变换。串口完整回显和完整运动等待会存档；回显不当作舵机到位、夹持力或独立实物真值。

```powershell
.\tools\start_sorting_loop.ps1 -Mode Stop
```

Stop阻止后续指令；没有硬件反馈保证已发送的舵机运动立即停止。异常、缺回显、部分写入、图像核验失败或进程中断会保留`pending.json`，重启不能重发。检查并处理实物、恢复已核对状态后，按记录编号记入人工处置：

```powershell
.\tools\start_sorting_loop.ps1 -KnownItem -Mode Review -TaskId 记录编号 -Observation '现场检查与恢复情况'
```

Review只记录人工处置，不改成自动成功。确认恢复后再手动移除本机`local-only/STOP_SORTING`；未知占用或遗留设备锁不能直接当空闲处理。
