# 可复用技能包

- [免重训新物品接入](add-sort-category/README.md)：文字或框选参考图生成独立提示类别包，
  预览原图掩码、评估正负样本并导出候选；不改现役绑定或发机械动作。工位小样本未达标
  的结果保留，独立新类别实物验收仍待完成。

- [PYNQ 加速核自检与性能诊断](pynq-accelerator-check/README.md)：可独立复制的
  Skill、离线硬件文件检查、CPU参考比对、已有双核服务适配器及测试。模拟/回放和
  真实板端证据分别标注，使用范围与本轮验证见技能说明。

## 历史动态回收分拣工作流

按最终方案确认样品与回收流→采集并标注输送视频→训练YOLO11n→部署CUDA/ROCm服务→构建PL图像核及编码器RTL→实测位移、相机延迟、机械接触时序→标定观察区及抓取窗口→无动作预测核验→物理拦截与分类盒复核→分带速CPU/PL对照及完整指标归档。

入口与复现细节见[Windows手册](../docs/windows_final.md)和[输送带部署](../docs/conveyor_setup.md)。软件与RTL仿真不代替实机。
